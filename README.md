# Dance Control

App web instalable (PWA) para preparar y dar clases de baile: velocidad sin cambiar el tono, secciones con loop y entrada 5-6-7-8, conteo, temporizador por bloque y biblioteca de coreografías con video.

## Publicar en GitHub Pages
1. Crea un repositorio en GitHub y sube todo el contenido de esta carpeta (index.html debe quedar en la raíz).
2. Settings → Pages → Source: "Deploy from a branch" → rama `main`, carpeta `/ (root)` → Save.
3. En 1–2 minutos tendrás un link tipo `https://TU-USUARIO.github.io/NOMBRE-REPO/`.

## Instalar en el celular
- **Android (Chrome):** abre el link → menú ⋮ → "Instalar app" / "Agregar a pantalla principal".
- **iPhone (Safari):** abre el link → botón Compartir → "Agregar a pantalla de inicio".

## Notas
- Las canciones se cargan desde el celular y no se suben a ningún servidor.
- Secciones, clases y coreografías (con sus videos) se guardan en el navegador de cada dispositivo.
- Si cambias archivos y quieres forzar la actualización, cambia `dance-control-v1` en `sw.js`.
